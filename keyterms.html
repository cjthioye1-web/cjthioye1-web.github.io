Key Terms

1- Meta data
This is data about data, and in this context provides information embedded within a webpage's code This is information will never show up within the display and is located within the head section of a website which displays elements in the tabs above. It is used by search engines to know more about a webpage.

2- Semantics
This is the use of HTML tags which specify the meaning of the content within them. This provides information to web and web developers about the intended role of a page's content. Other types of semantics can give context to the structure of the content.

3- Non-Semantics
This is the use of HTML tags which do not specifiy the meaning the content within them. They are simply containers of page content that provide a more proper layout and should be used wisely. They are meant more for styling.

4- Class
It is a group of attributes meant to manipulate specfic elements of a page. This can be applied to several types of elements and provide consistent overall design for them. These classes are created with the use of CSS and implemented within HTML.

5- ID
This identifier is similar to the uses of class except that it's attributes are applied to only one element within a page. It can also be used to link or anchor to other sections of the page with the use of the certain tags like the < a > tag.
